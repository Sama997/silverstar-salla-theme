# Silver Star Global UI V2

استبدل الملفين الحاليين في مستودع GitHub بهذه النسخة:

- silverstar-enhance.css
- silverstar-enhance.js

ثم استخدم في سلة:

CSS مخصص:
@import url("https://cdn.jsdelivr.net/gh/Sama997/silverstar-salla-theme@main/silverstar-enhance.css");

JavaScript مخصص:
var script = document.createElement('script');
script.src = 'https://cdn.jsdelivr.net/gh/Sama997/silverstar-salla-theme@main/silverstar-enhance.js';
document.head.appendChild(script);
